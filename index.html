Case notes

Problems I was brought in to fix

Short notes on real issues from past projects, what was going wrong, and what I changed.

Value Score
Problem

A lead sync broke every 50 leads

API authentication on an AWS EC2 cron job kept failing, and duplicate leads stalled the sync.

Fix

Gave every lead a unique identifier, which stopped duplicates from stalling the sync.

Eventus Security
Problem

Forms could be submitted whatever the user selected

A validation loophole let users send forms regardless of their selections.

Fix

Caught in structured UAT before production, one of 3 critical defects found through monthly release testing.

WhiteGlobal
Problem

Reps could move a deal to any stage they wanted

Nothing stopped reps from skipping or jumping between pipeline stages.

Fix

Enforced the pipeline with Zoho Blueprint and role-based access control, so deals follow the defined stages in order.

WhiteGlobal
Problem

Scope kept changing after the build started

Late requests meant work was rebuilt, and clients could break their own setup through misconfiguration.

Fix

Introduced written client sign-off on requirements before build, with later changes billed as change requests. Rework dropped by about 25%.
